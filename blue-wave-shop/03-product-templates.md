# Blue Wave Shop 상품 설명 템플릿 (한·영·일)

상품을 등록할 때 **복사 → [ ] 부분만 바꿔서 → 붙여넣기** 하면 됩니다.
말투는 `01-brand-guide.md`의 원칙(쉽고, 짧고, 고객 입장에서)을 따릅니다.

---

## 0. 사용 방법

1. 아래에서 옷 종류에 맞는 템플릿을 고릅니다.
2. `[대괄호]` 부분을 실제 정보로 바꿉니다.
3. Shopify 관리자 → **제품** → 상품 선택 → **설명** 칸에 한국어를 붙여넣습니다.
4. **Translate & Adapt** 앱에서 영어·일본어 칸에 각각 붙여넣습니다.
5. 태그는 `02-categories.md`의 규칙대로 붙입니다.

### 상품명 규칙

```
[라인/특징] + [옷 종류] + [핵심 장점]
```

| 언어 | 예시 |
|---|---|
| 한국어 | 웨이브 쿨링 래시가드 긴팔 |
| English | Wave Cooling Long Sleeve Rash Guard |
| 日本語 | ウェーブ クーリング 長袖ラッシュガード |

- 40자 이내로 짧게 쓰세요. 길면 모바일에서 잘립니다.
- 색상과 사이즈는 상품명에 넣지 말고 **옵션(Variant)** 으로 만드세요.

## 3. 자주 쓰는 표현 사전

| 한국어 | English | 日本語 |
