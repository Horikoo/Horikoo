# Blue Wave Shop 브랜드 가이드

종합 의류 쇼핑몰 **Blue Wave Shop**의 색상, 슬로건, 말투, 로고 방향을 정리한 문서입니다.
Shopify 테마 설정, SNS, 상품 사진, 포장지에 모두 같은 기준을 쓰면 브랜드가 하나로 보입니다.

---

## 1. 브랜드 한 줄 소개

| 언어 | 문장 |
|---|---|
| 한국어 | 바다처럼 자유롭게, 파도처럼 강하게. 일상부터 운동, 현장까지 입는 옷. |
| English | Free like the ocean, strong like the wave. Clothes for every day, every workout, every job. |
| 日本語 | 海のように自由に、波のように力強く。毎日も、トレーニングも、現場も。 |

### 브랜드 이야기 (회사 소개 페이지용)
> 프로 격투기 선수로 링에 서고, 건설 현장에서 땀 흘리고, 바다에서 돌고래 투어를 운영하며
> 배운 것이 있습니다. **좋은 옷은 편하고, 튼튼하고, 기분 좋게 만든다**는 것.
> Blue Wave Shop은 그 경험을 담아 누구나 어디서든 자신 있게 입을 수 있는 옷을 고릅니다.

## 2. 브랜드 색상

| 이름 | 색상 코드 | 용도 |
|---|---|---|
| **Deep Navy** (깊은 바다) | `#0B3D5C` | 로고, 제목, 기본 글자, 상단 메뉴 |
| **Ocean Blue** (바다) | `#1F6FA8` | 버튼("장바구니 담기", "구매하기"), 링크 |
| **Wave Aqua** (파도) | `#4FB3D9` | 강조 배경, 아이콘, 배너 포인트 |
| **Sand** (모래) | `#F4EBDD` | 섹션 배경, 상품 카드 배경 |
| **White** (흰 포말) | `#FFFFFF` | 기본 배경 |
| **Coral** (산호) | `#E8573F` | **세일·할인 표시에만** 사용 |

### 색상 사용 규칙
1. 화면의 약 60%는 흰색·모래색, 30%는 네이비·블루, 10%는 아쿠아·코랄로 맞추세요.
2. 코랄(빨간빛)은 세일과 품절 경고에만 써야 눈에 확 띕니다.
3. 버튼은 항상 Ocean Blue 바탕에 흰 글자로 통일하세요.
4. 연한 아쿠아(`#4FB3D9`) 위에는 흰 글자를 쓰지 마세요. 잘 안 읽힙니다. 네이비 글자를 쓰세요.

### Shopify에 적용하는 방법
온라인 스토어 → 테마 → **사용자 지정** → 테마 설정 → **색상**에서 위 코드를 입력하면 됩니다.

## 4. 글쓰기 말투

| 원칙 | 좋은 예 | 피할 예 |
|---|---|---|
| 친근하고 쉽게 | "땀이 빨리 말라서 운동할 때 좋아요." | "고기능성 흡습속건 원단 적용" |
| 짧고 자신 있게 | "세탁기에 돌려도 튼튼해요." | "아마도 내구성이 괜찮을 것으로 예상됩니다." |
| 고객 입장에서 | "키 175cm, 70kg이면 M 사이즈를 추천해요." | "사이즈표를 참고하세요." |

- 한국어는 **"~해요"체**로 통일합니다.
- 영어는 짧은 문장, 일본어는 **です・ます体**로 씁니다.

## 5. 로고 방향

**기본 아이디어:** 파도 한 줄 + 글자 "BLUE WAVE"

| 시안 | 설명 |
|---|---|
| A. 파도 라인 | 글자 위에 한 번 굽이치는 파도 선. 가장 깔끔하고 옷 라벨에 넣기 좋아요. |
| B. 원형 엠블럼 | 원 안에 파도와 "BW" 이니셜. 모자, 가방 자수에 잘 어울려요. |
| C. 파도 + 주먹 | 파도 끝이 주먹 모양. 운동복·격투기 라인 전용 서브 로고로 쓰기 좋아요. |

- 글꼴: 굵고 둥근 고딕 계열 (예: Montserrat Bold, Pretendard Bold)
- 로고는 **네이비 버전, 흰색 버전** 두 가지를 꼭 만들어 두세요. 어두운 사진 위에는 흰색 버전을 씁니다.

## 6. 사진 스타일

- 밝은 자연광, 바다·하늘·도시 거리 배경
- 상품 단독 사진은 **흰색 또는 모래색 배경**으로 통일
- 운동복은 실제로 움직이는 모습, 작업복은 현장 느낌으로 촬영
- 모든 상품 사진은 같은 비율(정사각형 1:1 또는 세로 4:5)로 맞추기
