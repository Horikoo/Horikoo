배당표 — 한 줄에 같은 그림 3개 (× 베팅)

줄: 블록마다 5줄 (가로 3줄 + 대각선 2줄).
9칸 같은 그림: 한 블록 9칸이 모두 같으면 그 블록 당첨금 ×10.
스킬 블록: 당첨 줄이 하나라도 있는 블록은 금색으로 빛납니다. 스킬 블록 2개 = +10 × 베팅, 3개 = +30 × 베팅.
게임 방법: 모든 칸은 빈칸으로 시작합니다. 시작 → 미리보기에 다음에 들어갈 그림 3개가 보입니다 (그림은 바뀌지 않음). 블록 1·2·3 아래의 스톱을 누르면 미리보기 그림 3개가 그 블록의 다음 세로줄(1 → 2 → 3)에 들어갑니다. 어느 블록에 넣을지 직접 고르세요. 9줄이 다 차면 점수를 계산합니다.
키보드: Enter = 시작 · A / S / D = 스톱 1 / 2 / 3 · Space = 베팅 · M = 소리 켜기/끄기
